ZX81 Emulator v

Open a ZIP or TZX file to view its programs.
Controls

F1 Record or stop an MP4 video of the main screen (256x192).
Shift+F1 Record or stop an MP4 video of the full canvas (320x240).
F2 Save the main screen (256x192) as a ZX Spectrum .scr file.
Shift+F2 Save the full canvas (320x240) as a .png image.
F3 Show or hide the frame and 8x8 character alignment grid.
F5 Pause or continue the emulator.

Picture alignment
Hold Cmd (Mac) or left Alt (Windows) and press an arrow key. Each press moves the picture one pixel; the adjustment resets when a program or model is loaded.

Programs and ZIP files
Choose Open program... to load a .P, .O, .Z81, .TZX or .ZIP file. ZIP contents appear beside the screen: click an entry to select it as the tape. The first program starts automatically; for later parts, enter LOAD "" on the ZX81. Use Eject to remove the tape and close the list.
